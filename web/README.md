# Laura Piñeros — Portfolio site

Editorial personal portfolio (Next.js).

## Run

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
